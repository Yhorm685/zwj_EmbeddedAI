# 题目与验收证据

依据《Helios 27赛季电控组招新考核题》任务 04 和通用提交要求。题面截止时间为 11 月 30 日 12:00。

| 题目要求 | 可核查的交付物 |
| --- | --- |
| 在 STM32F407 上部署小型神经网络，用 MPU6050 识别走路、跑步和静止 | 六轴原始采集批次、有标签的独立测试集、固件、模型版本与板端逐窗预测 |
| 解释输入、采样、预处理、滑窗、网络和量化 | 采样配置、通道与特征顺序、训练和转换脚本、参数量、标定数据来源 |
| CMSIS-NN 或自写定点算子，说明内存布局及峰值 RAM | 算子版本及调用、权重与激活存放位置、编译链接报告、运行时水位 |
| 板上实测并列表给出时延、RAM、Flash、准确率及与 PC 浮点误差 | 同版 ELF/map、串口原始结果、封存窗口、测量边界、样本数、三端对照表 |
| 运行效果可观察 | 串口实时输出与实物视频，包括动作切换和性能指标 |
| 仓库内提交模型、转换脚本、开发文档、演示视频、AI 会话及完整 Git 历史 | 有效文件、复现命令、问题记录、脱敏会话导出、各阶段提交 |

工程目标为准确率 ≥90%、各类召回率 ≥85%。记录每项实际测值和限制；评分题未给定这两个百分比。测试集冻结后用于最终评估，任何后续模型改动保留版本记录。
